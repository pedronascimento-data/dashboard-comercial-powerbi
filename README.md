# Dashboard Comercial — Power BI

Projeto de portfólio em desenvolvimento para construção de um **dashboard comercial no Power BI**, com foco em transformar dados de vendas em indicadores úteis para acompanhamento gerencial.

> **Status:** em desenvolvimento. O repositório ainda está sendo estruturado e os arquivos do dashboard serão adicionados nas próximas etapas.

## Objetivo

Criar uma solução de BI capaz de acompanhar indicadores comerciais e facilitar análises por período, produto, cliente e equipe de vendas.

## Indicadores planejados

- Faturamento
- Quantidade vendida
- Ticket médio
- Evolução mensal
- Participação por categoria/produto
- Desempenho de vendedores
- Ranking de clientes
- Comparação com metas
